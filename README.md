# SnowfallMac — macOS snow overlay prototype

Нативный прототип на Swift/AppKit. Рисует снег в прозрачном оконном слое, не должен перехватывать клики мыши, показывает управление в строке меню.

## Самый простой способ собрать без Xcode на своём Mac

В проект уже добавлен GitHub Actions workflow. Он собирает универсальное приложение для Apple Silicon (`arm64`) и Intel (`x86_64`) на облачном macOS runner с установленным Xcode. На своём компьютере Xcode устанавливать не нужно.

1. Создай **Private** репозиторий на [github.com/new](https://github.com/new). Название, например, `SnowfallMac`.
2. Распакуй этот архив. В корне распакованной папки находятся `.github`, `SnowfallMac.xcodeproj`, `SnowfallMac`, `README.md` и `build.sh`.
3. На странице пустого репозитория выбери **Add file → Upload files** и перетащи туда всё содержимое распакованной папки, включая скрытую папку `.github`. В Finder скрытые файлы показываются сочетанием `Command + Shift + .`.
4. Внизу нажми **Commit changes**. Если workflow загрузился в правильную папку `.github/workflows`, сборка автоматически запустится после коммита в `main`.
5. Открой вкладку **Actions**, выбери **Build SnowfallMac** и открой последний запуск. Дождись зелёного статуса `Success`.
6. Внизу страницы запуска, в секции **Artifacts**, скачай `SnowfallMac-universal`. В архиве будет `SnowfallMac.app` и файл контрольной суммы.

Если автоматический запуск не начался: открой **Actions → Build SnowfallMac → Run workflow**. Кнопка доступна, когда workflow уже находится в ветке по умолчанию.

## Первый запуск скачанного приложения

Артефакт собран с ad-hoc подписью: для сборки не нужны Apple Developer account и сертификат. Это не Developer ID-подпись и приложение не нотарифицировано Apple. При первом запуске macOS может показать предупреждение Gatekeeper. Попробуй нажать правой кнопкой на `SnowfallMac.app` → **Open / Открыть**. Если система всё ещё блокирует запуск, можно снять quarantine-атрибут только у этого приложения командой:

```bash
xattr -dr com.apple.quarantine "/путь/к/SnowfallMac.app"
```

Запускай команду только для приложения, собранного из этого исходного кода и скачанного из своего репозитория.

## Локальная сборка

Если позднее появится доступ к Xcode, открой `SnowfallMac.xcodeproj` и выбери схему `SnowfallMac`, либо выполни `./build.sh`.

## Состояние прототипа

- Значок снежинки и управление из строки меню.
- Несколько уровней интенсивности.
- Прозрачный overlay поверх экранов; `ignoresMouseEvents` пропускает взаимодействия к окнам под ним.
- Получение геометрии окон через CoreGraphics, без чтения их содержимого.
- Простое накопление снега у нижней границы экрана.

Пока это каркас, а не законченная копия KoiArt: Dock, точная маска перекрывающихся окон, осыпание при перетаскивании и полировка эффекта ещё требуют реализации и тестирования на реальном Mac.
