# Snowfall для macOS — снег поверх окон (v0.5)

Только снежный режим. Прозрачный слой поверх рабочего стола: хлопья падают в разных слоях глубины, ложатся на верхние кромки окон, Dock и нижний край экрана, образуют сугробы. Сугробы можно смахнуть курсором, а при перетаскивании окна снег сползает и осыпается.

Приложение живёт в строке меню (значок снежинки) и не перехватывает клики.

## Что умеет

- **Metal-рендер.** Хлопья — инстансированные мягкие спрайты, сугробы — треугольная сетка. Кадры синхронизированы с частотой дисплея (`MTKView`), 30 fps в режиме энергосбережения.
- **Два слоя на каждом мониторе.** Дальний снег — между иконками рабочего стола и окнами, ближний — поверх окон и Dock.
- **Ветер.** Curl-noise: хлопья плавно закручиваются, а не дёргаются.
- **Сугробы.** Два слоя высот: рыхлый свежий снег и уплотнённая основа. Осыпание по углу естественного откоса, сход через края, медленное таяние.
- **Окна.** Снег лежит на верхней кромке каждого окна. Закрытые частично окна обрезаются по интервалам: снег виден только там, где окно действительно не перекрыто.
- **Перетаскивание окна.** Снег по инерции сползает назад и частично осыпается; при броске окна — сильнее.
- **Курсор.** Движение мыши сметает снег вдоль всего пройденного отрезка, поднимает порошок и закручивает воздух вокруг; на трекпаде — лёгкий тактильный отклик. Хлопья возле курсора становятся прозрачнее, чтобы не мешать читать.
- **Dock.** Реальный размер Dock берётся через Accessibility (нужно разрешение, см. ниже).
- **Тёмная тема.** Сугробы подстраиваются под светлую и тёмную тему.
- **Энергия.** На батарее и в режиме энергосбережения снега вдвое меньше, частота кадров ниже. Рендер ставится на паузу, когда экран спит или окно закрывает весь дисплей (полноэкранное приложение).
- **Меню:** старт/стоп, очистка сугробов, «Только Finder», интенсивность (лёгкий / обычный / метель), разрешение для Dock, автозапуск. Настройки сохраняются.

## Самый простой путь: VS Code на Mac

Нужен Mac (macOS 13+) и Swift. Достаточно Command Line Tools — полный Xcode не обязателен.

1. Один раз в Терминале: `xcode-select --install`
2. Установи [VS Code](https://code.visualstudio.com/) и расширение **Swift** (`sswg.swift-lang`) — VS Code сам предложит его при открытии папки.
3. Открой папку проекта: **File → Open Folder…**
4. Нажми **⌘⇧B** (или **Terminal → Run Build Task**) — задача «Собрать .app». Либо в терминале VS Code: `./build_app.sh`
5. Готовое приложение появится в `dist/Snowfall.app`. Запусти его двойным кликом или задачей **«Собрать и запустить»** (`./build_app.sh --run`).

Другие задачи (⌘⇧P → *Tasks: Run Task*): универсальная сборка Apple Silicon + Intel (нужен полный Xcode), быстрая проверка компиляции, остановка приложения.

## Без Mac под рукой

Windows и Linux собрать это приложение не могут: нужны фреймворки Apple. Если Mac нет — сборка делается в облаке:

1. Залей проект в репозиторий на GitHub (хоть приватный).
2. Вкладка **Actions** → последний запуск **Build SnowfallMac** → внизу **Artifacts** → `SnowfallMac-universal`.

В архиве — универсальное `SnowfallMac.app` (Apple Silicon + Intel) и контрольная сумма.

## Первый запуск

Приложение подписано ad-hoc (без аккаунта Apple Developer) и не нотаризовано. macOS может показать предупреждение Gatekeeper:

- нажми правой кнопкой на приложение → **Открыть**; или
- сними карантин только с этого приложения:

```bash
xattr -dr com.apple.quarantine /путь/к/Snowfall.app
```

### Снег на Dock

Снег ложится на Dock, только если приложению разрешён доступ в **Системные настройки → Конфиденциальность и безопасность → Универсальный доступ**. В меню есть пункт «Снег на Dock: разрешить доступ…». Приложение читает только размер и положение панели Dock, содержимое окон не читается. Без разрешения всё остальное работает, просто на Dock снега не будет.

После каждой пересборки с новой ad-hoc подписью macOS может сбросить это разрешение — включи его заново.

### Автозапуск

Пункт «Запускать при входе» работает, если приложение лежит в «Программах» (или другой постоянной папке).

## Структура проекта

| Файл | Назначение |
|---|---|
| `Package.swift` | Swift Package для VS Code и командной строки |
| `build_app.sh` | Сборка `.app`, подпись, запуск |
| `.vscode/` | Задачи сборки и рекомендуемые расширения |
| `SnowfallMac/Sources/main.swift` | Точка входа (приложение без значка в Dock) |
| `SnowfallMac/Sources/AppDelegate.swift` | Меню, окна поверх экранов, сон/пробуждение, автозапуск |
| `SnowfallMac/Sources/SnowOverlayView.swift` | Симуляция: хлопья, ветер, сугробы, окна, курсор |
| `SnowfallMac/Sources/SurfaceTracker.swift` | Опрос окон, движение и закрытие, перекрытия |
| `SnowfallMac/Sources/SnowRenderer.swift` | Metal: шейдеры и отрисовка |
| `SnowfallMac/Sources/WindowGeometryProvider.swift` | Геометрия окон (CoreGraphics) и Dock (Accessibility) |
| `SnowfallMac/Sources/SnowIntensity.swift` | Уровни интенсивности |
| `SnowfallMac/Sources/AppSettings.swift` | Сохранение настроек |
| `SnowfallMac.xcodeproj` | То же самое для Xcode; используется облачной сборкой |

## Честные ограничения

- Код проверяется компиляцией в облаке (GitHub Actions), но внешний вид и поведение на реальном экране автор кода пока не видел. Параметры (плотность, размеры хлопьев, ветер, цвета сугробов) вынесены в константы в `SnowOverlayView.swift` — их легко подкрутить.
- Это независимая реализация по описанию и наблюдаемому поведению, не копия кода KoiArt.
- Поддерживается Dock только внизу экрана.
- Окна считаются по списку окон системы; окна в других рабочих столах (Spaces) не учитываются.
